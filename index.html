1 Rich Menu คืออะไร และใช้ทำอะไร

  • Rich Menu คือ “เมนูปุ่มลัด” ที่แสดงด้านล่างหน้าจอแชทของ LINE OA
  • ผู้เรียนกดปุ่มแล้วไปยัง ลิงก์/หน้าเว็บ/ไฟล์ หรือส่ง ข้อความอัตโนมัติ เพื่อช่วยให้เข้าถึงห้องเรียนได้เร็ว
  • เหมาะมากสำหรับ “ห้องเรียนออนไลน์” เพราะรวมทุกอย่างไว้ที่เดียว (สื่อการเรียนรู้, ตารางกิจกรรม, ถาม-ตอบ ฯลฯ)

2 วิธี “เพิ่มเพื่อน” เพื่อเข้าใช้งาน LINE OA Kru Nui

วิธีที่ 1 (แนะนำ) : กดลิงก์เพิ่มเพื่อน

  1. เปิดลิงก์ https://line.me/R/ti/p/@124xnyoq
  2. กด เพิ่มเพื่อน (Add friend) แล้วกด แชท
  3. จะเห็น Rich Menu ด้านล่างหน้าจอแชท

วิธีที่ 2 : สแกน QR Code

  1. เปิด LINE → กดปุ่มสแกน QR
  2. สแกน QR Code ในหัวข้อ “ลิงก์สำคัญ” ด้านบน
  3. กดเพิ่มเพื่อน แล้วเริ่มใช้งาน

วิธีที่ 3 : ค้นหาด้วย LINE ID

  1. เปิด LINE → เพิ่มเพื่อน → ค้นหา ID
  2. พิมพ์ @124xnyoq → กดค้นหา → เพิ่มเพื่อน

3 ปุ่มใน Rich Menu (6 ปุ่ม) กดแล้วได้อะไร

  • สื่อการเรียนรู้ → ไปยัง Google Drive/เว็บไซต์รวมสื่อ
  • ตารางกิจกรรม → เปิด Google Calendar ของห้องเรียน (ดูตารางเรียน/วันสำคัญ/กิจกรรม)
  • ครูสั่งงาน → ดูงานที่ครูมอบหมาย (ลิงก์/หน้าเว็บ/โพสต์)
  • นักเรียนส่งงาน → ส่งงานผ่านฟอร์ม/อัปโหลด/ช่องทางที่กำหนด
  • ถาม-ตอบ → ส่งข้อความ/คำถามเข้าห้องเรียน (มักตั้งเป็น “ข้อความอัตโนมัติ” เพื่อเปิดแชททันที)
  • เรียนออนไลน์ → ลิงก์เข้าห้องเรียนออนไลน์ (เช่น Google Meet)

4 วิธีใช้งานสำหรับนักเรียน/ผู้ปกครอง

4.1 กดปุ่ม “สื่อการเรียนรู้”

  • แตะปุ่ม → ระบบจะพาไปยังแหล่งสื่อ (เช่น โฟลเดอร์ Google Drive / เว็บไซต์ห้องเรียน)
  • เลือกบทเรียน/ไฟล์ตามหัวข้อ แล้วเปิดอ่าน/ดูวิดีโอได้ทันที

4.2 กดปุ่ม “ตารางกิจกรรม”

  • แตะปุ่ม → เปิด Google Calendar ของห้องเรียน
  • นักเรียนดูได้ทั้ง “วันนี้”, “สัปดาห์”, “เดือน” และเห็นวันสำคัญ/วันหยุด/วันสอบ

4.3 กดปุ่ม “ครูสั่งงาน”

  • แตะปุ่ม → เข้าหน้างานที่ครูมอบหมาย
  • อ่านรายละเอียดงาน + วันส่ง + วิธีส่ง

4.4 กดปุ่ม “นักเรียนส่งงาน”

  • แตะปุ่ม → เปิดฟอร์ม/หน้าอัปโหลด
  • ตรวจชื่อ-ชั้น-เลขที่ให้ถูกต้องก่อนกดส่ง

4.5 กดปุ่ม “ถาม-ตอบ”

  • แตะปุ่ม → ระบบจะส่งข้อความเริ่มต้น (เช่น “ถาม-ตอบ เรื่องวิชาการ การเรียน”) เพื่อเปิดบทสนทนา
  • พิมพ์คำถามเพิ่มเติมได้ทันที

4.6 กดปุ่ม “เรียนออนไลน์”

  • แตะปุ่ม → เข้าห้องเรียนออนไลน์ (เช่น Google Meet)
  • แนะนำให้เข้า ก่อนเวลา 5 นาที เพื่อเช็คเสียง/กล้อง/เน็ต

5 วิธีใช้งานสำหรับครู/ผู้ดูแล OA (ตั้งค่า/แก้ไข Rich Menu แบบย่อ)

5.1 เข้าไปที่หน้า LINE Official Account Manager (บนคอม)

  1. เปิด Chrome → ไปที่ https://manager.line.biz/
  2. ล็อกอินบัญชีที่เป็นเจ้าของ OA
  3. ไปที่เมนู ริชเมนู (Rich menu)

5.2 แก้ไขปุ่มในริชเมนู

  1. เลือกริชเมนูที่กำลังใช้งาน
  2. กด แก้ไข → เลือกพื้นที่ปุ่ม → ตั้งค่า “แอ็กชัน”
  3. แอ็กชันที่ใช้บ่อย:
    • ลิงก์ (URL) → ใส่เว็บ/ไดรฟ์/ปฏิทิน/Meet
    • ข้อความ (Text) → ให้ส่งข้อความเริ่มต้น (เช่น “ถาม-ตอบ…”) เพื่อเปิดแชท
  4. กด บันทึก และ เผยแพร่/ใช้งาน (ถ้ามีปุ่ม)

6 เชื่อม Google Calendar กับปุ่ม “ตารางกิจกรรม”

6.1 เตรียมลิงก์ปฏิทิน (Public/Embed)

  1. เปิด Google Calendar (คอมพิวเตอร์จะสะดวกที่สุด)
  2. เลือกปฏิทินของห้องเรียน → ตั้งค่าให้เข้าถึงแบบ “สาธารณะ/แชร์ได้” (Public)
  3. คัดลอกลิงก์ปฏิทิน (เช่นลิงก์นี้): https://calendar.google.com/calendar/u/0/embed?src=d3f6a12ca7e04d51dbf55ad079f80f34619c07c8a967eeede95f0a7382eef299@group.calendar.google.com&ctz=Asia/Bangkok

6.2 นำลิงก์ไปใส่ใน Rich Menu

  1. ไปที่ LINE OA Manager → เมนูริชเมนู
  2. เลือกปุ่ม “ตารางกิจกรรม”
  3. ตั้งค่าแอ็กชันเป็น ลิงก์ (URL)
  4. วางลิงก์ Google Calendar → บันทึก → เผยแพร่

  • Broadcast คือ “การส่งข้อความประกาศ” จาก OA ไปยังผู้ที่เป็นเพื่อนอยู่แล้ว

8 ปัญหาที่พบบ่อย (FAQ)

Q1: นักเรียนกดปุ่มแล้วไม่ไปหน้าเว็บ

  • ให้เช็คว่าเป็น “ลิงก์เต็ม” และขึ้นต้นด้วย https://
  • ลองเปิดลิงก์ในเบราว์เซอร์ก่อน แล้วค่อยนำไปใส่ Rich Menu

Q2: นักเรียนไม่เห็น Rich Menu

  • ต้องเพิ่มเพื่อน OA ก่อน
  • ให้ลองปิด-เปิดแอป LINE ใหม่

Q3: กด “ถาม-ตอบ” แล้วส่งข้อความซ้ำหลายครั้ง

  • เป็นปกติถ้าตั้งแอ็กชันเป็น “ข้อความ” — ให้พิมพ์คำถามต่อได้เลย
  • ถ้าต้องการลดการซ้ำ สามารถเปลี่ยนเป็น “เปิดลิงก์ฟอร์มถาม-ตอบ” แทนได้
